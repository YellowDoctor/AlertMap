Інтерактивна фізична карта України на основі мікроконтролера **ESP32-C3-SuperMini** та адресної стрічки **WS2815B (12V)** на 128 світлодіодів. Кожен світлодіод відповідає конкретному району чи великому місту України та відображає поточний статус повітряної тривоги в реальному часі.

---

## ✨ Основні можливості

- 🔄 **Дані в реальному часі**: пряме опитування API [alerts.in.ua](https://alerts.in.ua) з підтримкою кешування HTTP `If-Modified-Since` (економія трафіку та захист від лімітів 429).
- 📍 **128 районів та міст України**: точний маппінг за новим адміністративним устроєм (2020) з підтримкою актуальних перейменувань (*Шептицький, Звягель, Самар, Берестин* тощо).
- 🧠 **Розумна маршрутизація тривог**:
  - Якщо тривога оголошена на **всю область** — одночасно підсвічуються всі райони цієї області.
  - Якщо тривога **точкова** (по району чи місту) — підсвічується саме цей район.
- 🎨 **Рівні небезпеки**:
  - 🟢 **Зелений** (`0x00FF00`): Все спокійно (відбій тривог).
  - 🟡 **Жовтий** (`0xFFFF00`): Загроза ударних БПЛА (дрони).
  - 🔴 **Червоний** (`0xFF0000`): Ракетна / балістична небезпека або артилерійський обстріл.
  - 🟠 **Помаранчевий** (`0xFF8000`): Часткова тривога.
  - 🔵 **Синій** (`0x0000FF`): Режим офлайн / точка доступу Wi-Fi.
- 🎬 **5 режимів індикації нової тривоги** (налаштовуються через Web UI):
  1. **Плавна зміна (Fade)** — м'який колірний перехід за ~500 мс.
  2. **Миготіння району (Blink)** — 5 спалахів району з тривогою (2 секунди) для привернення уваги, потім постійний колір.
  3. **Стробоскоп (Strobe)** — 8 швидких яскраво-білих спалахів (маячок), після чого колір тривоги.
  4. **Біжуча хвиля (Wave)** — світлова хвиля прокочується по всій карті від заходу до сходу.
  5. **Постійне дихання (Breathe)** — плавна синусоїдальна пульсація яскравістю (40%..100%) на всіх активних тривогах.
- 🌙 **Автоматичний нічний режим**: налаштування годин (наприклад, 23:00 - 07:00), плавне приглушення яскравості та синхронізація київського часу через NTP (`pool.ntp.org`).
- 🌐 **Сучасний веб-інтерфейс (SPA)**: темна тема, адаптивність під смартфони, кольорові пікери, повзунки яскравості, повна автономність (без зовнішніх CDN).
- 📶 **Captive Portal**: якщо Wi-Fi не налаштовано або зв'язок втрачено, ESP32 піднімає мережу `AlertMap-XXXX` з автоматичним відкриттям сторінки введення Wi-Fi.
- ☁️ **Повне OTA оновлення по повітрю**:
  - Завантаження нових релізів **напряму з GitHub** (`firmware.bin` та `littlefs.bin`).
  - Оновлення через веб-інтерфейс файлом з браузера з відображенням прогресу.

## 🔌 Апаратна частина та схема підключення

### Компоненти:
1. **Плата**: ESP32-C3-SuperMini (4MB Flash, RISC-V 160MHz)
2. **Стрічка**: WS2815B (12 Вольт, 128 адресованих діодів, вбудовані IC, резервна лінія)
3. **Блок живлення**: 12V 3A - 5A якісний імпульсний БЖ
4. **Понижуючий модуль (Step-Down)**: DC-DC 12V -> 5V (наприклад, LM2596 або міні-модуль MP1584EN)

### Схема підключення:

```text
[ Блок Живлення 12V ]
       │
       ├─────────────────────────────────> +12V Стрічки WS2815B
       │
       ├──────────> [ Step-Down 12V->5V ]
       │                   │
       │                   └─────────────> 5V (VIN) пін ESP32-C3
       │
       └───────────────────┬─────────────> GND (Спільна земля!)
                           ├─────────────> GND Стрічки WS2815B
                           └─────────────> GND пін ESP32-C3

[ ESP32-C3-SuperMini ]
       GPIO 4 ───────────────────────────> DI (Data In) Стрічки WS2815B
                                           BI (Backup In) Стрічки -> з'єднати з GND або DI першого діода
```

> **Важливо**: обов'язково об'єднайте всі мінусові дроти (GND) в одну точку — блок живлення, стрічку та плату ESP32.

## 🚀 Встановлення та прошивка

### Варіант 1. Через PlatformIO (рекомендовано для розробників)

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/YellowDoctor/AlertMap.git
   cd AlertMap
   ```
2. Підключіть ESP32-C3 через USB до комп'ютера.
3. Прошийте код програми:
   ```bash
   pio run -t upload
   ```
4. Завантажте файлову систему веб-інтерфейсу (LittleFS):
   ```bash
   pio run -t uploadfs
   ```

### Варіант 2. Прошивка готових бінарних файлів (без встановлення середовища)

У папці `binaries/` знаходяться скомпільовані бінарники останнього релізу:
- `bootloader.bin`
- `partitions.bin`
- `firmware.bin`
- `littlefs.bin`

Прошивка за допомогою `esptool.py`:
```bash
python -m esptool --chip esp32c3 write_flash \
  0x0000 binaries/bootloader.bin \
  0x8000 binaries/partitions.bin \
  0x10000 binaries/firmware.bin \
  0x3B0000 binaries/littlefs.bin
```

## 📶 Перше підключення та конфігурація

1. Подайте живлення на плату.
2. Світлодіоди виконають синьо-жовту вітальну анімацію та перейдуть у синій колір (режим пошуку мережі).
3. З телефону чи комп'ютера підключіться до створеної точки доступу:
   - **Wi-Fi назва**: `AlertMap-XXXX` (останні 4 символи MAC адреси)
   - **Пароль**: `alertmap1`
4. У вікні Captive Portal, що відкриється (або перейдіть на `192.168.4.1`), введіть ім'я та пароль вашого домашнього Wi-Fi.
5. Після підключення до домашнього роутера відкрийте IP-адресу карти в браузері.
6. У вкладці **⚙️ Налаштування**:
   - Введіть ваш API токен з [devs.alerts.in.ua](https://devs.alerts.in.ua).
   - Оберіть бажаний режим анімації, кольори та яскравість.
   - Збережіть налаштування!

## ☁️ Оновлення прошивки по повітрю (OTA)

Прошивка підтримує оновлення прямо з GitHub Releases:
1. У налаштуваннях вкажіть ваш GitHub репозиторій:
   - Власник: `YellowDoctor`
   - Репозиторій: `AlertMap`
2. На вкладці **🔄 Оновлення** натисніть **«Перевірити оновлення»**.
3. Плата звірить поточну версію з останнім релізом на GitHub і, якщо вийшла нова версія, покаже список змін та кнопку **«Оновити прошивку»**.
4. Плата самостійно завантажить `firmware.bin` (і за потреби `littlefs.bin`), верифікує та перезавантажиться без використання дротів.
